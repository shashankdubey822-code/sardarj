## 3. COMPONENT-BY-COMPONENT EXIT ANIMATION & TIMING SPECIFICATIONS

Every interactive element has distinct entry, hover, and **exit animation parameters** to ensure snappy, tactile responsiveness:

```
                                  ANIMATION CURVES & TIMING
          ENTRY: cubic-bezier(0.16, 1, 0.3, 1) [Ease Out Expo - 350ms]
          HOVER: cubic-bezier(0.2, 0.8, 0.2, 1) [Ease Out Quad - 200ms]
          EXIT:  cubic-bezier(0.4, 0, 1, 1)    [Ease In Quad - 220ms]
```

### 3.1 Modal & Drawer Exit Behavior
- **Trigger**: User clicks Close (X), presses `Escape`, or taps backdrop.
- **Exit Motion**: Modal scale drops from `1.0` to `0.94`, opacity fades from `1.0` to `0.0`, while translating downward by `12px` (`translateY(12px)`).
- **Exit Duration**: Exactly `220ms` via `cubic-bezier(0.4, 0, 1, 1)`.
- **Exit Text Spec**: Inside modals, any helper text or exit confirmation reads in `13px` (`0.8125rem`) `--color-text-caption`, smoothly dissolving before the modal closes.

### 3.2 3D Showcase Panel Collapse / Exit
- **Trigger**: User closes 3D viewer or switches to flat gallery view.
- **Exit Motion**: WebGL canvas decouples rendering loop (`cancelAnimationFrame`), canvas opacity drops from `1.0` to `0.0` over `180ms`, container height smoothly shrinks from `560px` to `0px` with `ease-in-out` (`duration: 250ms`).

### 3.3 Toast & Notification Dismissal
- **Exit Motion**: Slides right by `100%` (`translateX(100%)`) with opacity dropping to `0.0` over `200ms`.
